# Vibe Coding AI2

Приложение проверяет, является ли введённый пользователем год високосным.

## Как это работает

- При запуске программа открывает диалоговое окно для ввода года.
- Ввод проходит валидацию:
  - поле не должно быть пустым
  - значение должно быть целым числом
  - год должен находиться в диапазоне от 1 до 9999
- После проверки приложение сообщает результат во всплывающем окне.

## Запуск

1. Убедитесь, что на компьютере установлен Python.
2. Запустите `main.py`.
3. Введите год в появившемся окне и нажмите `OK`.

## Результат

- Если год високосный, отображается сообщение, что год является високосным.
- Если нет — отображается сообщение, что год не является високосным.
- При ошибке ввода выводится сообщение об ошибке.
